# منوفولیو (Menu Canvas)

نمایشگاه تعاملی منوی دیجیتال برای رستوران‌ها و کافه‌ها، ساخته‌شده با React، TypeScript، TanStack Start و Tailwind CSS. رابط کاربری کاملاً فارسی و راست‌به‌چپ است و چهار قالب منوی متفاوت را همراه با تغییر اندازه‌ی نمایشگر (موبایل / تبلت / دسکتاپ) نشان می‌دهد.

## امکانات

- **پوسته‌ی نمایشگاه**: نوار بالایی چسبان برای جابه‌جایی میان چهار قالب و سه اندازه‌ی نمایشگر.
- **چهار قالب**: بیسترو و کافه‌ی دست‌ساز، مینیمال مدرن، غذای خیابانی شهری و رستوران لوکس.
- **امکانات منو**: کارت غذا با تصویر، قیمت، برچسب‌های رژیمی و وضعیت موجودی؛ دسته‌بندی و جستجوی زنده؛ فیلتر برچسب‌ها؛ پنجره‌ی جزئیات غذا با علاقه‌مندی؛ سبد سفارش با تعداد و محاسبه‌ی خودکار جمع جزء، مالیات و مبلغ کل؛ بنر اطلاعات رستوران.
- **ثبت سفارش**: اطلاعات مشتری و انتخاب ارسال با پیک، تحویل حضوری یا صرف در رستوران (با فیلدهای شرطی).
- **نمونه‌ی روش‌های پرداخت**: پرداخت آنلاین (درگاه شبیه‌سازی‌شده و رسید)، پرداخت در صندوق (بلیت سفارش با QR) و کارت‌به‌کارت (ثبت شماره‌ی پیگیری). همه‌ی پرداخت‌ها نمایشی و سمت کاربر هستند.

> قیمت‌ها به تومان و نرخ مالیات ۱۰٪ است (`src/features/menu/data.ts`).

## شروع کار

پیش‌نیاز: [Bun](https://bun.sh) (یا Node.js نسخه‌ی ۲۰ به بالا همراه با npm).

```sh
bun install
bun run dev        # http://localhost:8080
```

## دستورها

| دستور | توضیح |
| --- | --- |
| `bun run dev` | اجرای سرور توسعه |
| `bun run build` | ساخت نسخه‌ی تولید |
| `bun run preview` | پیش‌نمایش نسخه‌ی ساخته‌شده |
| `bun run test` | اجرای تست‌ها |
| `bun run lint` | بررسی کد |
| `bun run format` | قالب‌بندی با Prettier |

## استقرار

نسخه‌ی تولید با Nitro ساخته می‌شود و هدف پیش‌فرض آن Cloudflare (`cloudflare-module`) است. برای استقرار در جای دیگر، مقدار `defaultPreset` را در `vite.config.ts` تغییر دهید (مثلاً به `node-server`).

## فونت

فونت وزیرمتن (Vazirmatn) از طریق بسته‌ی `@fontsource/vazirmatn` همراه پروژه بارگذاری می‌شود و به سرویس خارجی (مثل Google Fonts) وابسته نیست.
